API 与程序化访问

兼容 OGC STAC 1.0，支持按时间/空间/波段/云量过滤；提供签名URL/令牌下载与分块流式访问。

GET /stac/search
{
  "bbox":[73.3,18.2,135.0,53.6],
  "datetime":"2023-01-01/2024-12-31",
  "collections":["landsat-c2-l2","sentinel-1-grd"],
  "query":{"eo:cloud_cover":{"lt":20},"gsd":{"lte":10}}
}
curl -H "Authorization: Bearer <token>" \
  'https://api.geointel.dev/stac/search?bbox=...&datetime=...'

建设标准与质量控制

  • 元数据：ISO 19115/19139、STAC 1.0、eo:bands、proj、raster、ml:training-extent
  • 标注协议：任务导向（分类/分割/检测/变化），类别体系可映射到 FAO LCCS/ESA WorldCover
  • 数据治理：版本化（DVC）、数据血缘、统计报告、偏见与伦理声明、可重复性清单
  • 评测基准：统一划分 train/val/test，跨域迁移与时序外推；提供基线模型与开箱脚本
